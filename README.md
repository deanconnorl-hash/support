# Support & privacy pages

Served with GitHub Pages. These URLs are referenced from App Store Connect for
each app, and App Review checks that they load, so nothing here should 404.

| App | Support | Privacy |
|---|---|---|
| Patience | `index.html` | `privacy.html` |
| Pagoda | `pagoda.html` | `pagoda-privacy.html` |
| Canary | `canary.html` | `canary-privacy.html` |

Plain HTML, no build step. Edit a file, commit, push; Pages redeploys itself.
